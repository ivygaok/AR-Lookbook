INSTALL
1. Unzip AR-Lookbook-Flower-Scan.zip. Keep your previous project as a backup.
2. Open this new folder in VS Code. It is a complete project, not a patch.
3. On your Mac open https://hiukim.github.io/mind-ar-js-doc/tools/compile/
4. Add the new assets folder's target images in this EXACT order:
   FIRST target-01.png — the small portrait/apron crop (unchanged).
   SECOND target-02.png — the WHOLE popup background (new version).
   Compile both together in one operation. Do not use the older cropped
   target-02.png from a previous project folder.
5. Download the compiled result. Rename it EXACTLY targets-flower.mind.
   Put it inside THIS project's assets folder before uploading.
6. In your EXISTING GitHub AR-Lookbook repository select Add file > Upload files.
   From the NEW project folder, drag its CONTENTS into GitHub:
   index.html, app.js, style.css, START-HERE.txt, and the entire assets folder.
   Do not drag the outer AR-Lookbook-Flower-Scan folder.
   Commit changes and wait for the Pages deployment to complete.
7. Verify this link downloads a file instead of showing 404:
   https://ivygaok.github.io/AR-Lookbook/assets/targets-flower.mind
8. Open https://ivygaok.github.io/AR-Lookbook/ in a new Android Chrome Incognito
   tab. Confirm you see TWO pictures and 'Point at the flower.'
   Tap Start AR, allow the camera, and test both printed pages.

TARGET AND PLAYBACK DETAILS
Recognition uses background details that remain visible around the popup.
Some partial views may work; there is no guarantee that every small portion
will contain enough distinctive details. The page fold, popup shadows, glare,
and how much background is visible can affect recognition. Test the actual
assembled book. No digital video or image is placed over the popup flower.

The popup clip continues while the AR page remains open and visible. Switching
apps or tabs stops the experience. Sound mutes/unmutes either experience.
Scan another page stops the popup clip; briefly aim away before rescanning the
same flower. Scanning the portrait can also switch directly to its video.
