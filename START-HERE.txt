TWO AR EXPERIENCES — COMPLETE PROJECT

This folder contains both experiences, including all existing media and styles.
1. Portrait: video with sound, using the accepted flat-section target and
   existing video size and placement.
2. Popup page: audio only, using the flat background on the RIGHT side.
   No digital image or video covers the physical popup.

Start AR enables sound for both. Each clip loops while its target is tracked.
Scanning away pauses playback; returning resumes it. Switching between targets
pauses the other clip. Sound mutes both. Stop camera stops both.

SETUP
1. Unzip AR-Lookbook-Two-Experiences.zip. Keep your old project as a backup.
2. Open the new AR-Lookbook-Two-Experiences folder in VS Code.
3. On your Mac open https://hiukim.github.io/mind-ar-js-doc/tools/compile/
4. Add these two images from the new assets folder IN THIS EXACT ORDER:
   FIRST target-01.png (portrait apron/brooch patch)
   SECOND target-02.png (right-side brick wall/graffiti background)
   Confirm the compiler lists the portrait patch first. Compile BOTH together
   in a single operation, not separately. This sets targetIndex 0 and 1.
5. Download the result. Rename it targets-book.mind and put it inside the
   new project's assets folder, next to target-01.png and target-02.png.
6. Open your existing AR-Lookbook repository on GitHub.
   Choose Add file > Upload files. From the NEW project folder, drag in its
   CONTENTS: index.html, app.js, style.css, START-HERE.txt, and assets folder.
   Do not drag the outer project folder. Commit changes.
7. After deployment, open https://ivygaok.github.io/AR-Lookbook/ on Android.
   Use a new Incognito tab if the previous version is cached.
8. Start AR and test each physical page. For the popup page, aim so the
   background to the RIGHT of the flower is clearly visible. A closer view of
   that area can help initial recognition. No reprinting is needed.

OLD FILES
Your old targets.mind, targets-flat.mind, flat-section.png, and video.mp4 can
remain in GitHub; this version does not reference them. Keep video-v2.mp4.
The URL stays the same, so a QR code to it will open both experiences.

TARGETS
Target 1 pixels are unchanged from the flat-section version you accepted.
Target 2 is a crop of original Target 2.png: (1450,70) to (2000,800), within
one side of the spread and outside the center popup footprint.
Recognition may vary with lighting, glare, shadows, page curvature, and popup
occlusion. The camera must see the background patch, not just the pink flower.

MEDIA
Portrait video retained without changes.
Popup audio is a louder copy of Trigger 2.mp3, normalized toward -16 LUFS.
Original uploaded files were not changed.
